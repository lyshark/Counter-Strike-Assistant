The name of this project is A Case Study of Perspective Aiming Assistance Function in Counter-Strike Game Version v91. It aims to demonstrate and analyze the underlying implementation mechanism of auto-aim assistance programs for shooting games, helping developers understand the overall architecture and detailed technical principles of such game assistance programs at the code level.
